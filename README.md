# Beyond-the-Smoke
## Investigating the Impacts of Cannabis Legalization on Societal Drug Patterns in Canada
Empirical analysis of cannabis legalization in Canada using binomial logistic regression on Statistics Canada microdata.

This repository contains an academic PNAS format paper analyzing the effects of the 2018 cannabis legalization in Canada on the consumption of cannabis, alcohol, and hard drugs.

The study uses cross-sectional microdata from Statistics Canada surveys conducted before and after legalization (2017 and 2019) and applies binomial logistic regression models to evaluate changes in consumption patterns.

## 🔍 Abstract
The legalization of recreational cannabis in Canada in October 2018 represented a major shift in drug policy. This paper investigates whether legalization led not only to increased cannabis consumption, but also to spillover effects on alcohol and hard drug use.

Using repeated cross-sectional survey data from Statistics Canada and binomial logistic regression models, we find a significant increase in cannabis consumption following legalization, no statistically significant increase in hard drug use, and a notable change in alcohol consumption patterns. These findings challenge the common assumption that cannabis legalization creates a broadly permissive environment for drug use.

---

## 📊 Data and Methodology
- **Data source:** Statistics Canada (Health Canada surveys, 2017 & 2019)
- **Method:** Binomial logistic regression with interaction terms
- **Focus:** Cannabis, alcohol, and selected hard drugs
